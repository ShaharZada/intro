# בת מצווה — הרכבת הסרטון

100 תמונות, 2 שניות כל אחת, שלושה שירים. הפלט: קובץ MP4 אחד.

- `make_video.py` — מרכיב את הסרטון
- `select_photos.py` — בורר את התמונות מאלבום גדול (ראה `RUNBOOK.md`)

---

## החשבון

| | |
|---|---|
| 100 תמונות × 2 שניות | 3:20 |
| כרטיס פתיחה + כרטיס סיום (אופציונלי) | +0:07 |
| **סה"כ** | **~3:27** |
| כל שיר מתוך השלושה מקבל | **~1:09** |

דקה ותשע שניות לשיר זה קטע אחד — פזמון, לא שיר שלם. לכן כדאי
**לבחור ידנית את הקטע מכל שיר** (איך — בהמשך), ולא להסתמך על ההתחלה.

אם רוצים יותר מקום למוזיקה: `--per-photo 3` נותן 5:00 ו-1:40 לכל שיר.
המספר `2` הוא ברירת המחדל בכל מקרה, כמו שביקשת.

## המוזיקה — צריך את הקבצים

הסקריפט לא מוריד מוזיקה. צריך שלושה קובצי אודיו על הדיסק:

1. Taylor Swift — Love Story
2. יש בך הכל
3. רק מה שאת אוהבת

מאיפה: קנייה ב-iTunes Store / Amazon / Bandcamp נותנת קובץ להורדה.
מנוי Spotify או Apple Music **לא** נותן קובץ שאפשר לייצא. אם יש CD —
ייצוא דרך Music/iTunes. פורמטים נתמכים: `mp3, m4a, aac, wav, flac, ogg, opus`.

> שימוש בשירים מוגנים בסרטון משפחתי פרטי הוא בסדר. העלאה ליוטיוב
> ציבורי כנראה תסומן ותושתק — אם צריך להעלות, השאר את הסרטון "פרטי"
> או "לא רשום".

## התקנה

```bash
cd batmitzvah
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install pillow pillow-heif python-bidi imageio-ffmpeg tqdm numpy opencv-python
```

`imageio-ffmpeg` מביא ffmpeg מוכן בלי התקנת מערכת. אם כבר יש ffmpeg
ב-PATH הוא ישתמש בו. אפשר גם להצביע ידנית: `export FFMPEG=/path/to/ffmpeg`.

## שלב 1 — לסדר את התמונות

הסקריפט לוקח את התמונות **לפי סדר שם הקובץ** (מיון טבעי: 9 לפני 10).
שתי דרכים לקבל סדר כרונולוגי:

**אם התמונות באו מ-`select_photos.py`** — הן כבר ממוספרות כרונולוגית,
פשוט תן את תיקיית `selected` ותוסיף את הדוח כדי לשמור על הסדר גם
בין תיקיות הגילאים:

```bash
python3 make_video.py --photos ./selected --order-csv ./selected/selection_report.csv ...
```

**אם בחרת ידנית** — תמספר בעצמך: `001_...jpg`, `002_...jpg` וכן הלאה.

## שלב 2 — הרצת בדיקה (30 שניות)

לפני שמרנדרים 100 תמונות, בודקים על 10:

```bash
source venv/bin/activate

  --photos ./photos \
  --out ./test.mp4 \
  --preview 10 \
  --song "love_story.m4a"
```

תפתח את `test.mp4` ותבדוק: הכיוון של התמונות נכון? המעברים בקצב טוב?
הזום לא אגרסיבי מדי? הרקע בצדדים של תמונות פורטרט נראה טוב?

## שלב 3 — לבחור את הקטע מכל שיר

התחביר הוא `"קובץ:התחלה:אורך"` בשניות. למשל, פזמון שמתחיל בדקה 1:02
ורוצים ממנו 69 שניות:

```bash
--song "love_story.m4a:62:69"
```

אם משמיטים את האורך, השיר מקבל חלק שווה מהזמן שנשאר:

```bash
--song "love_story.m4a:62"        # מתחיל ב-1:02, האורך מחושב אוטומטית
--song "yesh_bach_hakol.mp3"      # מההתחלה, אורך אוטומטי
```

הדרך הפרקטית למצוא את נקודת ההתחלה: תפתח את השיר בכל נגן, תרשום
את הזמן שבו רוצים להיכנס, ותמיר לשניות (1:02 → 62).

## שלב 4 — ההרצה האמיתית

```bash
python3 make_video.py \
  --photos ./photos \
  --out ./batmitzvah.mp4 \
  --song "love_story.m4a:62" \
  --song "yesh_bach_hakol.mp3:45" \
  --song "rak_ma_sheat_ohevet.mp3:30" \
  --per-photo 2 \
  --title "נועה" \
  --subtitle "בת מצווה · תשפ״ו" \
  --end-title "מזל טוב!"
```

לוקח 5-8 דקות ל-100 תמונות ב-1080p. הכותרות אופציונליות — בלי
`--title` הסרטון מתחיל ישר בתמונה הראשונה.

## מה קורה מתחת למכסה

1. **נרמול** — יישור לפי EXIF (תמונות אייפון מסובבות), פענוח HEIC,
   והתאמה ליחס 16:9. תמונת פורטרט מקבלת **רקע מטושטש מעצמה** במקום
   פסים שחורים.
2. **קליפ לכל תמונה** — עם תנועת קן-ברנס עדינה. הכיוון מתחלף
   (זום פנימה / החוצה / אלכסון) כדי שלא תיווצר תחושת לופ.
3. **מעברים** — `xfade` בין כל שתי תמונות. השרשור נעשה בקבוצות של 25
   ואז הקבוצות מתחברות ביניהן, גם כן במעבר רך — שרשרת של 99 מעברים
   בפקודה אחת מפילה את ffmpeg על צריכת זיכרון.
4. **תזמון מדויק** — כל תמונה תופסת **בדיוק** 2 שניות בציר הזמן;
   המעבר חופף בתוך התקציב הזה ולא נוסף עליו. 100 תמונות = 200 שניות,
   לא 200 ועוד קצת.
5. **פסקול** — חיתוך הקטעים, השוואת עוצמות בין השירים (`loudnorm` —
   חשוב, כי הקלטות מסחריות שונות מאוד בעוצמה), קרוס-פייד של 2.5
   שניות בין שיר לשיר, ופייד-אאוט של 4 שניות בסוף.

## כוונון

| רוצה | דגל |
|---|---|
| תמונות איטיות יותר | `--per-photo 2.5` |
| מעבר ארוך/קצר יותר | `--xfade 0.9` / `--xfade 0.3` |
| רק דיסולב, בלי גליצ'ים | `--transition fade` |
| חיתוכים ישרים, בלי מעברים | `--transition none` |
| בלי אפקט זום | `--no-zoom` |
| פסים שחורים במקום רקע מטושטש | `--background black` |
| סרטון אנכי לסטורי | `--size 1080x1920` |
| 4K | `--size 3840x2160` (איטי בהרבה) |
| קרוס-פייד ארוך בין שירים | `--audio-xfade 4` |
| רינדור מהיר יותר | `--jobs 8` (לפי מספר הליבות) |
| בלי מוזיקה, רק לבדוק את התמונות | בלי `--song` בכלל |

## פתרון תקלות

**`לא נמצא ffmpeg`** — `pip install imageio-ffmpeg`, או `export FFMPEG=/path/to/ffmpeg`.

**תמונות מסובבות ב-90 מעלות** — לא אמור לקרות, הנרמול מיישר לפי EXIF.
אם כן: התמונה עצמה שמורה מסובבת בלי EXIF, תסובב אותה ידנית.

**קובצי HEIC נדלגים** — `pip install pillow-heif`.

**הכותרת בעברית יוצאת הפוכה** — `pip install python-bidi`.

**הכותרת יוצאת ריבועים** — הגופן לא תומך בעברית. תן גופן אחר:
`--font /System/Library/Fonts/Supplemental/Arial.ttf` (מק) או
`--font C:/Windows/Fonts/arial.ttf` (חלונות).

**"המוזיקה קצרה מהווידאו"** — קטע שביקשת חורג מאורך השיר. תקצר את
נקודת ההתחלה או תוסיף שיר רביעי.

**נגמר הזיכרון / ffmpeg נהרג** — `--jobs 2`, ואם זה לא עוזר `--size 1280x720`.

**נשמע קליק בין השירים** — `--audio-xfade 4`.

**רוצה לראות את קבצי העבודה** — `--keep-temp`.
